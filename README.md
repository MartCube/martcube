<details>
<summary>For developers: run it locally</summary>

Requires Node 22+ and pnpm.

```bash
pnpm install
pnpm dev         # http://localhost:3000
```

| Script | What it does |
| --- | --- |
| `pnpm build` | Production build |
| `pnpm lint` | Lint and format check |
| `pnpm typecheck` | Type check |
| `pnpm test` / `pnpm test:e2e` | Unit tests / Playwright smoke tests (after `pnpm build`) |

Every push to `main` deploys to Netlify, and every pull request gets a preview link. Each feature lands as its own small pull request, so the history doubles as a build log.

</details>
